# Origem dos recursos visuais — versão 0.5

As quatro imagens `*-ia.png` foram geradas em 11/11/2026 para este protótipo escolar. As pessoas e cenas são fictícias. Os arquivos foram copiados integralmente; o enquadramento dos cartões é feito pelo CSS. Não é necessário conectar o aplicativo a uma IA para exibir essas imagens.

| Arquivo em `static/artes/` | Cena de exemplo |
| --- | --- |
| `alimentacao-ia.png` | Mulher apresentando um bolo caseiro em uma cozinha. |
| `artesanato-ia.png` | Artesã tecendo uma cesta de palha. |
| `rural-ia.png` | Produtor com farinha de mandioca e raízes. |
| `servicos-ia.png` | Pedreiro com capacete e luvas trabalhando com tijolos e colher. |

A orientação de geração foi fotografia realista horizontal, luz natural, contexto do Nordeste brasileiro, pessoa adulta e instrumentos de trabalho reconhecíveis no centro, sem textos, marcas ou montagens. As imagens são exemplos das atividades, não retratos dos profissionais do cadastro.

Os ícones de pessoas e objetos são desenhos SVG próprios do projeto. O símbolo do WhatsApp veio de [Bootstrap Icons](https://icons.getbootstrap.com/icons/whatsapp/), com licença MIT incluída em `static/LICENCA_BOOTSTRAP_ICONS.txt`. Seu desenho foi preservado e colocado sobre uma base verde. A logo do Batalha Conecta continua sendo a imagem fornecida pelo professor.

Para substituir uma foto, consulte `GUIA_PERSONALIZACAO.md`. Quando usar uma fotografia real em uma categoria, altere também seu campo `imagem_ia` para `False`.
