# Amostras das novas vozes

- `amostra-francisca.mp3` — voz feminina em português brasileiro.
- `amostra-antonio.mp3` — voz masculina em português brasileiro.

As duas amostras foram geradas pelo serviço online usado pelo `edge-tts`. Abra os MP3 para comparar. No aplicativo, selecione a voz em **Ajuda**.

Para narrar textos novos, é necessário ter internet e o serviço estar disponível. As amostras são arquivos fixos. Não substituem a conexão para gerar novas falas. `preparar_voz.py` gera novamente essas amostras.

Biblioteca utilizada: https://github.com/rany2/edge-tts
